# simpler sound harvester

A capstone-friendly, simplified piezoelectric energy harvester: a 5-part
passive design (piezo input -> bridge rectifier -> storage cap -> Zener
clamp -> output terminal), down from ~40 components in the original design.

- [`about.txt`](about.txt) - design rationale and simplifications
- [`kicad/`](kicad/) - KiCad schematic, PCB layout, and BOM
